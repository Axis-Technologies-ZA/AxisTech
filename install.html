DOCUMENTATION / DEPLOYMENT GUIDE

How to Install AxisOS

Everything you need to flash, boot, and install AxisOS 2.0 on real PC hardware, gaming laptops, or virtual machines. AxisOS ships as a universal hybrid UEFI + Legacy BIOS live image with instant desktop testing.

SYSTEM COMPATIBILITY

Hardware Requirements

AxisOS runs on standard 64-bit x86 hardware. It is optimized for responsiveness on modern NVMe drives while remaining fully compatible with older SATA SSDs and HDDs.

COMPONENT MINIMUM SPECIFICATION RECOMMENDED (GAMING & DEV)
Processor 64-bit Dual-Core x86_64 CPU (Intel / AMD) Quad-Core 2.5 GHz+ (Intel Core i5/i7/i9 or AMD Ryzen)
Memory (RAM) 4 GB System RAM 8 GB to 16 GB+ for Steam gaming and compilation
Storage 25 GB Available Disk Space 60 GB+ High-Speed NVMe or SATA SSD (Btrfs root)
Graphics (GPU) Intel HD Graphics, AMD Radeon, or NVIDIA GT/GTX NVIDIA RTX/GTX (PRIME Offload), AMD Radeon RDNA (FreeSync), or Intel Arc
Motherboard Firmware Legacy BIOS or 64-bit UEFI Modern UEFI with GPT Partition Table & AHCI SATA Mode
Display Resolution 1280 × 720 (720p HD) 1920 × 1080 (1080p FHD) or 4K with Fractional Scaling
Secure Boot Support: AxisOS includes a Microsoft-signed Shim (BOOTX64.EFI) and Debian-signed GRUB EFI binary for out-of-the-box Secure Boot support on most OEM motherboards. If your machine encounters an unauthorized key signature error, simply disable Secure Boot in your BIOS settings.

WALKTHROUGH

Step-by-Step Installation

Follow these steps sequentially to prepare your media, test your hardware live, and install AxisOS.

STEP 01 DOWNLOAD & VERIFY

Download the ISO Image

Obtain the latest stable hybrid ISO (axisos-v2.0-live-amd64.iso). Verify the SHA256 checksum to guarantee file integrity before flashing.

$sha256sum axisos-v2.0-live-amd64.iso
# Compare output against SHA256SUMS
STEP 02 MEDIA CREATION

Flash to a USB Flash Drive

Use an 8 GB or larger USB flash drive. Select your favorite imaging tool:

  • Rufus (Windows): Select Partition Scheme GPT, Target UEFI. Choose Write in DD Image mode if prompted.
  • balenaEtcher: Select ISO > Select Drive > Flash.
  • Ventoy: Simply drag and drop the .iso file onto your Ventoy USB drive.
# Linux CLI:
$sudo dd if=axisos-v2.0-live-amd64.iso of=/dev/sdX bs=4M status=progress oflag=sync
STEP 03 FIRMWARE & BOOT

Boot into AxisOS Media

Insert the USB drive into your powered-off computer. Power on and immediately tap your vendor's Boot Menu key to choose your USB device.

• ASUS: F8  • Dell: F12  • HP: F9
• Lenovo: F12  • Acer: F12  • MSI: F11

Tip: If Windows boots immediately, hold Shift while clicking "Restart" in Windows, then choose "Use a device" > USB Drive.

STEP 04 LIVE TESTING

Explore the Live Desktop

In the GRUB boot menu, select "Try AxisOS 2.0 (Live Desktop)". The system loads entirely into RAM without modifying your internal hard drive.

Test your Wi-Fi, monitor resolution, sound playback, and hardware brightness toggle to ensure complete hardware compatibility.

● RAM-Only Safe Exploration Mode
STEP 05 SETUP WIZARD

Run the AxisOS Installer

Double-click "Install AxisOS" on the desktop. The wizard guides you through:

  • Target Disk: Choose your SSD or NVMe drive.
  • Filesystem: Automatically generates EFI FAT32 and robust Btrfs root partitions.
  • User Account: Set your full name, username, computer hostname, and password.
$axisos-installer &
STEP 06 FINISH & REBOOT

Reboot into Your New System

Once the installer shows "Installation Complete", click Restart Now, remove the USB drive when prompted, and press Enter.

Your computer boots straight into the Cinnamon desktop with hardware acceleration, pre-configured Steam gaming, and full APT package management.

✓ Zero Post-Install Driver Hunting Required

FIRST STEPS

Post-Install Configuration

01 / PKG

System Updates & Repositories

AxisOS uses standard Debian Bookworm repositories alongside the Axis repository. Update your system using the GUI Update Manager or terminal:

$sudo apt update && sudo apt upgrade -y
02 / APPS

Installing Applications

Browse thousands of apps in the native Software Manager or install via command line using APT, dpkg, or Flatpak sandboxes:

# Native APT:
$sudo apt install vlc git build-essential
# Flatpak Sandbox:
$flatpak install flathub com.discordapp.Discord
03 / GAME

Steam & Proton Gaming Subsystem

Steam is pre-installed in the application menu. AxisOS automatically configures high vm.max_map_count, 32-bit Vulkan drivers, and Feral GameMode for high-FPS AAA gaming.

# Launch Steam with PRIME NVIDIA Offload (laptops):
$prime-run steam

ASSISTANCE

Troubleshooting & Frequently Asked Questions

Black Screen or GPU Freeze during Boot?

Some dedicated NVIDIA graphics cards require the basic modesetting framebuffer during initial live boot. In the GRUB boot menu, choose option 3. AxisOS 2.0 (Safe Graphics Mode - nomodeset). Once installed, the system's autodetection daemon will configure proprietary NVIDIA drivers.

VirtualBox / VMware Installation Settings

When running in a virtual machine, ensure you configure:

  • Enable EFI (special OSes only) in System settings.
  • Allocate at least 4 CPU cores and 4096 MB RAM.
  • Set Video Memory to 128 MB and select VMSVGA with 3D Acceleration enabled.

Dual-Booting Alongside Windows 11

Disable Fast Startup in the Windows Control Panel (Power Options) before installing. During installation, do not format your existing Windows EFI partition; AxisOS will install alongside it and automatically detect Windows in the GRUB boot menu.

Wi-Fi Card Requires Proprietary Firmware?

AxisOS includes Debian non-free-firmware packages by default (Intel Wi-Fi, Realtek, Broadcom). If an uncommon card is not recognized, temporarily connect Ethernet or USB tethering from your smartphone to download drivers via sudo apt install firmware-linux-nonfree.
