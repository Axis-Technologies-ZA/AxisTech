AxisOS

A high-performance Debian-based Linux operating system pairing the rock-solid stability of Debian Bookworm with the flagship Cinnamon desktop environment, high-speed C/CJS window management, GTK visual consistency, and out-of-the-box AAA gaming capabilities.

SYSTEM ARCHITECTURE

Engineered for Reliability & Speed

AxisOS rejects over-simplified mobile interfaces in favor of proven desktop engineering paradigms. Every layer of the operating system is built with native code, shared C libraries, and reactive runtime scripts.

01 / DE

Flagship Cinnamon Desktop & Muffin Compositor

The primary desktop environment relies on Muffin, a C-based window manager that drives window decorations, GPU-accelerated compositing, and rendering. The outer UI, smooth applet animations, status trays, and desklets are scripted in CJS (Cinnamon JavaScript runtime, a fork of GNOME's GJS), enabling rapid customization with native performance.

Cinnamon Desktop Muffin Window Manager (C) CJS (JavaScript Runtime)
02 / GTK

GTK Graphical Interface Toolkit

Across the OS, every native application renders through GTK (GTK3 & GTK4). GTK ensures pixel-perfect window scaling, uniform button states, crisp typography, and sub-pixel antialiasing across all resolutions from 720p to 4K displays.

GTK3 / GTK4 libxapp C Libraries Fractional Display Scaling
03 / PYTHON

Python & C Native Tooling Suite

System configuration utilities, hardware monitors, the Update Manager, Software Center, and background telemetry daemons are developed in Python and C, leveraging shared C bindings (python-xapp). Heavy computational tasks (media rendering, file I/O) are handled in native C.

Python 3.11+ Shared C Libraries Hardware Autodetect Daemons
04 / APPS

The X-Apps Traditional Desktop Philosophy

Following the philosophy of traditional desktop computing, native applications retain classic menubars (File, Edit, View), dedicated toolbars, and information-dense status bars. Key tools are never hidden behind hamburger menus or stripped down to mobile-first simplicity.

Desktop Agnostic Functionality Over Minimalism Persistent Status Bars
05 / DISPLAY

Display Server: Default X11 with Wayland Support

AxisOS defaults to the battle-tested X11 display server for rock-solid NVIDIA driver support, universal screen capture, and multi-monitor compatibility, while shipping with experimental Wayland support (Cage compositor) for low-latency modern graphics.

X11 Default Cage Wayland Experimental Working Brightness Controls
06 / PKG

Unified Package Management: APT, dpkg & Flatpak

System software is maintained using Debian's time-tested APT and dpkg package infrastructure, augmented with our native axis command-line tool. Seamless integration with Flatpak allows sandboxed modern apps from Flathub to be installed with zero dependency conflicts.

Debian Repositories Axis Package Manager Flathub Sandboxing
07 / GAMING

Pre-Installed Steam & Proton Gaming Subsystem

Valve's Steam client comes pre-installed in the desktop menu. The operating system kernel is pre-configured with vm.max_map_count = 2147483642, 32-bit multiarch libraries, Vulkan 1.3 async shaders, Feral GameMode, and NVIDIA PRIME render offloading for AAA Windows game compatibility via Proton.

Steam Pre-Installed Proton 9.0 Compatibility Feral GameMode Active Vulkan 1.3 Ready
08 / STYLE

Black, White & Mint Green Visual Identity

AxisOS is clad in a distinctive, modern visual identity: deep obsidian blacks (#0a0e0b), crisp whites, and vibrant mint green accents (#87cf3e). All application icons are crafted as bespoke geometric vector tiles, deliberately avoiding generic macOS clones.

Deep Obsidian (#0a0e0b) Mint Green (#87cf3e) Geometric Vector Iconography

PROJECT FILE / 002

Apex Overdrive

v3.0.1 STABLE RELEASE

A high-octane desktop gaming performance engine and live telemetry cockpit for Windows and Linux. Built with a modern C++ native core and a GPU-accelerated automotive gauge cluster, Apex Overdrive automatically elevates game process priorities, unlocks 0.5ms multimedia scheduling resolution, bypasses CPU core parking, and flushes standby RAM lists when a game launches — reverting every modification cleanly on exit.

OPTIMIZATION SUITE

Maximum FPS. Zero Micro-Stutters.

Apex Overdrive combines low-level operating system engineering with an immersive cyberpunk automotive racing aesthetic, providing tactile control and visual instrumentation over your hardware.

01 / CLUSTER

Automotive Car Cluster Cockpit & Shift LEDs

Canvas-rendered instrument cluster featuring real-time tachometer & speedometer dials for CPU Load, GPU Engine, and RAM Boost Utilization. Features authentic sports car ignition needle sweeps and a 10-stage sequential shift-light LED bar (Green → Amber → Redline).

Spring Needle Physics 10-Stage Shift Lights Center HUD Telemetry
02 / BENCHMARK

Automated PC Hardware Benchmark Scanner

Deep hardware inspection module that scans CPU architecture, physical/logical cores, dedicated GPU VRAM, memory speed, and NVMe SSD DirectStorage readiness upon launch, computing your official Gaming Capability Benchmark Score (Tier S+, S, A, or B).

Full HW Topology Scan Gaming Capability Score DirectStorage Verification
03 / TURBO

Warp Drive Turbo Boost & 0.5ms Timer Resolution

Unlocks aggressive CPU turbo boost mode, unparks 100% of CPU cores to prevent low-power sleep state delays, and lowers the Windows scheduling quantum from 15.6ms to 0.500ms for the lowest possible input latency and smoothest frame pacing.

0.5ms High-Precision Timer CPU Core Unparking Network Nagle Optimizer
04 / MEMORY

Instant Standby RAM Purge

Flushes cached standby memory lists and trims non-essential background process working sets on demand with pneumatic blow-off valve audio feedback, freeing gigabytes of memory without needing a reboot.

Standby Memory Flush EmptyWorkingSet API Pneumatic Audio FX
05 / GPU

DirectX Discrete GPU Routing & Clocks

Forces gaming executables directly to high-performance discrete GPUs via DirectX preferences, while interfacing with NVIDIA NVAPI and AMD ADL drivers to lock maximum performance clock states (P0).

DirectX GPU Routing NVAPI & AMD ADL Max P0 Clock State
06 / SAFETY

Transactional RAII Safety & Clean Rollback

Zero permanent system damage. Every optimization is guarded by RAII objects and a disk-backed rollback journal. Revert all tweaks back to factory defaults at any time with a single click or automatically upon game exit.

RAII Rollback Guards Crash-Resilient Journal Zero Permanent Changes
